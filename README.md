# Simulador de Proposta — Simples Dental

Ferramenta interna do time de vendas. Responde perguntas sobre a operação da
clínica, dimensiona os pacotes de crédito e monta a proposta para o cliente,
com opção de gerar a imagem para enviar no WhatsApp.

Arquivo único, sem build. A tabela de preços fica editável na própria tela e é
salva no navegador de quem usa.
